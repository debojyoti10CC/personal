# 🚀 Build on Celo – Kolkata Edition  
### India’s First-Ever Celo Hackathon Experience

## 📍 Event Overview
- **Event:** Build on Celo – Kolkata Edition  
- **Dates:** October 25–26  
- **Venue:** Offbeat CCU, Kolkata  
- **Organized by:** Rise In × Celo  
- **Team:** Light Frost 2  

The *Build on Celo* Kolkata edition marked a historic moment — **India’s first-ever Celo hackathon**. Over an intense 24-hour sprint, Offbeat CCU transformed into a high-energy innovation hub filled with builders, mentors, and Web3 enthusiasts.

This wasn’t just a competition. It was a deep, immersive dive into decentralized application development under real-world pressure.

---

## 💡 What We Built — *Celosave*
**Celosave** is a **vault-based decentralized application (dApp)** built on the **Celo blockchain**.

### 🔐 Core Idea
Celosave focuses on secure, smart-contract-driven fund management using a vault architecture, enabling transparent and decentralized saving mechanisms on-chain.

### 🛠️ Key Highlights
- Designed and implemented a **functional dApp** within 24 hours  
- Built **smart contracts** aligned with Celo’s architecture  
- Focused on **security, transparency, and usability**  
- Took the project from **idea → deployment** in a high-pressure environment  

This hands-on build process strengthened my understanding of:
- Blockchain architecture  
- Smart contract design  
- Decentralized application workflows  
- Rapid prototyping under time constraints  

No textbook could replicate this level of learning.
