### My First Step into Web3 & NFT-Based Gamification

##  Event Overview
- **Event:** Avalanche Team1 – Kolkata Edition  
- **Type:** Web3 Hackathon  
- **Milestone:** First Web3 Hackathon  

Participating in the **Avalanche Team1 Kolkata Edition** marked my **first hands-on entry into the Web3 ecosystem**. It was an immensely rewarding experience that introduced me to blockchain development through real-world building rather than theory.

---

##  Project — NFT Game Reward System
Our team built an **NFT-based game reward system** powered by **Avalanche’s Core Wallet**.

###  Concept
The idea was to integrate **NFT minting with gamification**, allowing players to:
- Earn rewards through gameplay  
- Mint NFTs as digital assets  
- Use blockchain-backed ownership to enhance player engagement  

This project became my first practical exposure to how **on-chain assets** can be used beyond speculation — as functional components of interactive systems.

---

##  Key Learnings & Implementation
Through this project, I gained hands-on experience with:

- 🔹 **Blockchain fundamentals** and wallet-based interactions  
- 🔹 **Core Wallet integration** within a Web3 application  
- 🔹 **NFT minting workflows**, from user action to on-chain asset creation  
- 🔹 Designing **secure, seamless user experiences** in decentralized apps  
- 🔹 Collaborating and problem-solving in a **time-bound, high-pressure hackathon environment**  

This hackathon helped bridge the gap between curiosity and actual blockchain development.
